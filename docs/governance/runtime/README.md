# Runtime Tool Inputs

This directory contains checked-in deterministic inputs consumed by existing
runtime reconstruction/validation tools. It is supporting technical material,
not current runtime evidence or mutation authority.

- `ST_DENIS_TWIN_PARITY_MANIFEST_V2.json` is the sanitized manifest consumed by
  the Twin tooling.
- `V7_PRODUCTION_TO_V10_TWIN_CONFIGURATION_MAPPING.md` is its checked mapping
  input.

Historical runtime evidence is archived under
[`docs/archive/governance-pre-simplification/runtime`](../../archive/governance-pre-simplification/runtime/).

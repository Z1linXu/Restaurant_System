## 发布范围与已知问题

- 压缩流程测试 #123 在首单异步渲染之前提交了 Update。首单票也包含新增项，Update 票仍严格按批次。这与现有 `PrintDispatcherServiceImpl.buildRenderRequest` 在普通票路径按订单读取当时所有行一致。该异步时序在本批次中未修改。建议 Production 发布前单独决策是否修复这一竞态。
- 建议 Chinatown 在 Staging 审核商品名、操作习惯和厨房预览，并确认外卖辣椒及加青的价格。未来 Production 使用单独的准确 SHA，保留 Production 核实后的原有面内加玉米价。上线使用单店菜单变更批次，附备份、回滚、门店试单和实体打印验证。
- Docker 磁盘占用 54%（剩余 27 GB）→ 55%（剩余 26 GB）。共享 Build Cache 为 8.407 GB，前后可回收均为 1.173 GB。本轮未清理共享缓存、旧镜像或数据库卷。Production 版本、容器与卷保留，Staging 前后端及数据库健康。

# Documentation Archive

Everything under this directory is historical context. It is outside the
default Agent reading path and cannot authorize current implementation,
deployment, data mutation or Phase transition.

## Contents

- [`governance-pre-simplification/`](governance-pre-simplification/) preserves
  the pre-2026-08-21 governance tree, including Planbooks, Handoffs, workflow
  documents, implementation evidence, acceptance evidence and deployment
  evidence. Its internal directory shape is retained to preserve forensic link
  context.
- [`legacy-root/`](legacy-root/) preserves superseded root/doc workflow,
  roadmap and execution-plan material with independent historical value.

Use [`docs/governance/AUTHORITY.md`](../governance/AUTHORITY.md) and
[`docs/governance/CURRENT_STATE.yml`](../governance/CURRENT_STATE.yml) for
current authority. Open archived material only for a specific historical or
forensic question.
